Welcome to Simple HTTP Server

A lightweight HTTP/1.1 static file server built with Java ServerSocket.

Features

  • HTTP/1.1 protocol parsing
  • Static file serving
  • Directory listing
  • MIME type detection
  • Path traversal protection
  • Error handling (400, 403, 404, 405, 500)
